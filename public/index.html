Accessibility statement

Relay targets WCAG 2.2 AA: full keyboard operability, visible focus, semantic landmarks, screen-reader announcements for new messages, respect for reduced-motion and forced-colors system preferences, and themes designed for deuteranopia, protanopia, tritanopia and monochrome vision. Status is always conveyed with icons and text, never colour alone.

About

Relay v2.0 — an accessible messaging app with no runtime dependencies: plain HTML, CSS and JavaScript on the front end, Node and SQLite on the back.
